# Selvara · Defensa final

Presentación de la entrega final del Plan de Marketing Digital para Selvara Estética Integral (Aisle Agency · ISEC · Práctica Profesionalizante IV · 2026).

Proyecto con fines educativos: Selvara es un cliente ficticio de cátedra.

## Cómo verla
Abrí `index.html` en el navegador o publicala con GitHub Pages (Settings → Pages → rama `main`, carpeta raíz).

## Controles
- ← → o barra espaciadora: avanzar y retroceder
- O: índice · N: notas · T: cronómetro · F: pantalla completa
